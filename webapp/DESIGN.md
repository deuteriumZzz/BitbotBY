# DESIGN — «Тёмный премиум-терминал»

Источник вида для `webapp/`. Прежний стиль «Приборная панель» (`docs/design/DESIGN.md`) — анти-референс:
от него остаются механика движения и состав функций.
Референсы (что берём): Dribbble — Multi-Asset Watchlist / Tactical Dashboard Blocks, Prop Firm Dashboard,
Pro Trading Platform; traderwaves.com — карта связей «источники → центр → результаты»; cryptonislabs — кабинеты.

## Style DNA

**Суть:** спокойный тёмный терминал — модульные карточки на глубоком фоне, крупные чистые цифры, один акцент у
действия и роста.

Профиль: спокойный · мягкая · лёгкий свет (отсвет, свечение линии графика) · плавное движение · баланс · без 3D.

**ОБЯЗАТЕЛЬНО**
1. Глубокий холодный фон; карточки на ступень светлее, граница 1px едва заметная, у верхней кромки — слабый отсвет.
2. Геометрия мягкая: карточка 16, вложенный блок 12, поле 10; кнопки, переключатели периода, фильтры и метки
   статуса — пилюли. Острых квадратных кнопок нет.
3. Модульная сетка карточек: промежуток 12–16, внутри 18–24; сверху строка показателей, дальше крупная карточка
   графика, рядом узкая колонка, ниже список или таблица.
4. Один акцент — зелёный роста: активное состояние, ключевая линия графика, «вкл». Падение — красный, внимание —
   янтарь, «идёт» — синий. Основная кнопка — светлая пилюля с тёмным текстом; выбранный сегмент — тоже.
5. Цифры крупные и чистые (Onest 600, трекинг −0.02em, табличные); подписи мелкие, обычным регистром, приглушённые.
   Моноширинный — только ID и колонки цифр.
6. Данные выразительные: плавная линия графика с мягким свечением и заливкой, тающей вниз; при наведении — точка и
   подсказка-пилюля; прогресс — штриховая шкала из делений.
7. Движение — готовое (барабаны цифр, стрелки, радар и ход монет по этапам, линейка стоп–цель, бегущие точки
   цепочки), без отскока; карточка появляется сдвигом на 8px с проявлением; hover поднимает тон, не масштаб.
8. Карта связей (как у traderwaves): источники слева → бот в центре → результаты справа, по линиям бегут точки —
   для «Подключений» и AI-цепочки.

**ЗАПРЕЩЕНО**
Неоновые и радужные градиенты на фон и пол-экрана · фиолетовое свечение · стекло и blur · квадратные «клавиши» ·
капс-подписи с разрядкой повсюду · карточки глубже двух уровней · фото, 3D-иллюстрации и эмодзи · больше одного
акцента.

**Эталоны**
- Кнопка: пилюля 36–40px; основная — светлая заливка и тёмный текст; вторичная — тон заливки + граница 1px;
  кнопка-иконка — круг 36px.
- Карточка: радиус 16, фон карточки, граница 1px, отсвет сверху; заголовок 14/600 обычным регистром + действие
  справа («Все →»).
- Поле: радиус 10, утопленный фон, граница 1px; фокус — светлое кольцо 2px с отступом.
- Метка статуса: пилюля 22–24px с тонированным фоном цвета статуса (+12.5%, «Funded», «Live»).
- Фокус: светлое кольцо 2px с отступом 2px, видно на любом фоне.
- Знак BitbotBY: шестигранник, монохромный.

## Токены

Единственный источник — `src/styles/tokens.css`. Палитра «Сталь».

| Токен | Значение | Роль |
|---|---|---|
| `--c-bg` / `--c-s1` / `--c-s2` / `--c-s3` / `--c-inset` | `#08090B` / `#101215` / `#15181C` / `#1B1F24` / `#0B0D10` | фон → карточка → hover → заливка управления; утопленный — поля |
| `--c-line` / `--c-line2` / `--c-ctl` | `#1E2228` / `#2A2F36` / `#67707C` | граница карточки / шов / рамка поля (≥ 3:1) |
| `--c-sheen` | `rgba(255,255,255,.035)` | отсвет у верхней кромки карточки (96px) |
| `--c-ink` / `--c-ink2` / `--c-ink3` | `#E6EAEF` / `#A3ABB6` / `#828B97` | текст / вторичный / подписи (≥ 4.5:1 на любом фоне) |
| `--c-up` = `--c-accent` / `--c-down` / `--c-warn` / `--c-run` | `#4BE08A` / `#FF5A5F` / `#FFC24B` / `#6FA8FF` | рост и акцент / падение / внимание / «идёт» — всегда со знаком ▲▼ |
| `--r-card` / `--r-inner` / `--r-ctl` / `--r-pill` | 16 / 12 / 10 / 999 | карточка / вложенный блок / поле / пилюля |
| `--font-text` / `--font-mono` | Onest 400–800 / JetBrains Mono | текст и показания / ID и колонки цифр |
| `--dur-fast` / `--dur-norm` / `--dur-slow` | 120 / 240 / 480 мс | `--ease-mech` = `cubic-bezier(.3,.7,.1,1)`, без отскока |

Контраст проверен расчётом: подписи ≥ 4.8:1 на самом светлом фоне, статусные цвета ≥ 6.2:1 к карточке.

Прежние имена (`--bg`, `--panel`, `--brand`, `--glow`, `--r` …) — алиасы новых токенов в конце `tokens.css`;
удаляются, когда все секции переедут. Новые примитивы и каркас — слой в конце `app.css` («Тёмный премиум-терминал»).
