# DESIGN — «Пульт»

Индустриальный брутализм для торгового бота: пульт управления, а не витрина.
Источник вида для `webapp/`. Прежний стиль «Приборная панель» (`docs/design/DESIGN.md`) — анти-референс:
от него остаются только механика движения и состав функций.

## Style DNA

**Суть:** точная сетка, жёсткие отсеки, данные — главный материал; цвет говорит только о состоянии.

Профиль: спокойный · острая · плоский · механика (S/R) · плотно · без 3D.

**ОБЯЗАТЕЛЬНО**
1. Почти чёрный нейтральный фон (не #000). Отсеки разделены линиями 1px через сетку (`gap: 1px` на тоне линии);
   2px — только между крупными зонами. Подложек-карточек нет.
2. Углы 90°, радиус 0. Исключения — круглые лампы-индикаторы и стрелочные шкалы.
3. Цвет — только статусы: рост, падение, внимание, «идёт» + нейтральная шкала серого. Выбор, фокус и основная
   кнопка — инверсия (светлая заливка, тёмный текст), не цвет.
4. Шрифты: тяжёлый гротеск — крупные цифры и заголовки (плотный трекинг); моноширинный — метки, ID, числа
   (метки капсом с разрядкой); текстовый гротеск — пояснения обычным регистром, понятными словами.
5. Плотность двухрежимная: плотные таблицы данных и крупные «приборные» показания с воздухом вокруг.
6. Движение механическое: без отскока, только transform/opacity, 120/240/480 мс. Готовые анимации
   (барабаны цифр, стрелки, радар, линейка стоп–цель, бегущие точки цепочки, тумблеры) сохраняются.
7. Заголовок отсека — одна структурная метка: `[ ПОЗИЦИИ · 03 ]` моноширинным капсом.

**ЗАПРЕЩЕНО**
Градиенты (кроме функциональных шкал вроде «Страха и жадности») · тени, свечение, glow · стекло и blur ·
скругления · неон и фиолетовый · scanlines, шум, кроссхейры, штрихкоды, ®™ и прочий псевдо-технический декор ·
эмодзи · карточки в карточках · больше одного цвета на одно действие.

**Эталоны**
- Кнопка: прямоугольник, рамка 1px, моноширинный капс; основная — инверсия; hover — фон на ступень светлее;
  нажатие — сдвиг на 1px.
- Отсек: полоса-заголовок `[ НАЗВАНИЕ ]` + счётчик справа, линия 1px снизу; внутри без рамок.
- Поле: фон на ступень темнее, рамка 1px, числа моноширинным; фокус — 2px светлая рамка.
- Строка таблицы, hover: фон на ступень светлее, слева полоса 2px цвета статуса строки.
- Фокус: сплошная светлая рамка 2px с отступом 2px, видна на любом фоне.
- Знак BitbotBY: шестигранник сохраняется, монохромный.

## Токены

Заполняются в ШАГ 2 (палитра) и ШАГ 3 (шрифты). Единственный источник — `src/styles/tokens.css`.
