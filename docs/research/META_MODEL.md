# Meta-Model (вероятность успеха сигнала)

Статус: **код и проверки готовы, модель не обучена** — не на чем: исходы сделок начали писаться в Decision Ledger только недавно.

## Назначение
По признакам сигнала (Local + SAC + волатильность + стакан) оценить вероятность, что сделка закроется в плюс. Эта вероятность — не «уверенность» LLM, не величина действия SAC и не прогноз: это отдельная величина, пригодная для размера позиции только после доказанной калибровки.

## Реализация
- `backend/bitbot/ai/reliability/meta_model.py`: логистическая регрессия на numpy (L2); LightGBM — необязательный адаптер (зависимость не добавлена).
- `backend/bitbot/ai/reliability/calibration.py`: Brier, ECE, reliability-корзины, Platt (демпфированный Ньютон), isotonic (PAV). Калибратор обучается только на validation.
- Дисциплина выборок: train → обучение, validation → калибровка, test → оценка один раз.

## Вердикт `usable`
Калибровочная выборка ≥ 200; Brier калиброванной не хуже сырой (допуск 0.002); калиброванная лучше константы «средняя частота успеха». На шумовых данных вердикт ложен (тест). Пороги — предложения.

## Связь с размером позиции
`bitbot.risk.advanced.kelly_from_meta`: Kelly от вероятности только при `usable=True`; поправка на неопределённость `p_eff = p − √(p(1−p)/n)`, половинный Kelly, потолок 20%. Не подключено к `RiskManager` (там Kelly по win rate).

## Данные для обучения
Метка: `outcome.pnl > 0` (net, после комиссий; `recorded=true`). Связь с признаками — по `decision_id` (`signals` ↔ `execution` ↔ `outcome` в Ledger). Утечки: признаки только из записей до решения, разбиение по времени с embargo.
