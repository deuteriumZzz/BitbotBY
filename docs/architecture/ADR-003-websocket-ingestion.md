# ADR-003 — WebSocket-ingestion рынка (Phase 4b)

Статус: **предложение, ждёт подтверждения владельца** (2026-11-23). Основа: [MASTER_SPEC_v2.md](MASTER_SPEC_v2.md) Phase 4b, [AUDIT_REPORT.md](AUDIT_REPORT.md) §10l.

## Решение

| Вопрос | Выбор | Почему |
|---|---|---|
| Клиент | `websockets` (уже в `requirements.txt`) + собственный разбор протокола Bybit v5 | Протокол — тонкий JSON (`subscribe`, `ping`). Существенная логика (целостность стакана по `u`, задержка по биржевому ts, переподключение, backpressure) наша при любом клиенте. `ccxt.pro` прячет `u` и биржевые метки за своей абстракцией; в проекте закреплён `ccxt==4.3.47`; `pybit` — новая зависимость. |
| Режим | Shadow: поток параллелен REST, на решения не влияет; REST — источник решений и эталон сверки | ТЗ: сначала Shadow → Paper → live; откат на REST при расхождении. |
| Приватный поток | Не подключён; реализована только обработка событий (дубли, порядок, машина состояний) | Подключение требует подписанной аутентификации, т.е. доступа к API-ключам; ключи — только из зашифрованного хранилища, а изменения безопасности — по явному решению владельца. |
| Формат событий | `orjson` не вводится; стандартный `json` | Нужен профиль по реальной нагрузке (пункт 5 реестра идей). |
| Шина событий (Redis Streams) | Не вводится | По ТЗ — только по отдельному ADR. |
| Хранение тиков/стакана | Не пишется | Триггер ClickHouse из ADR-001 (≥ единицы ГБ/нед) ещё не достигнут. |

## Что проверено живым замером (25 с, публичный поток, 2 символа)

Подписки `kline`/`orderbook.50`/`tickers`/`publicTrade` приняты; стакан получил snapshot и держался без пропусков `u` и без пересечений; задержка p50 ≈ 1 мс (относительно лучшего наблюдения, не абсолютная); пересоединений нет. Этого мало для приёмки: ТЗ требует ≥ 7 дней.

## Допущения, которые нужно сверить с документацией Bybit (§14)

URL и топики, допустимые глубины стакана, непрерывность `u` (`delta.u == last_u + 1`) на всех категориях, смысл `u == 1`, формат `kline` (`confirm`), период heartbeat. Живой замер их не опроверг, но и не доказывает.

## Exit (из ТЗ, не выполнен)

Замер ≥ 7 дней: доля пропусков стакана, число reconnect, p50/p99 lag, расхождение WS и REST по свечам; решения Shadow не хуже REST; chaos-тест на реальном обрыве при частичном исполнении.
