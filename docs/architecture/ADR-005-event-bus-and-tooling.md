# ADR-005 — Шина событий и инструменты ускорения

Статус: принято (2026-11-24). Основа: MASTER_SPEC_v2 реестр идей №2, 3, 5, 20–21; замеры ниже.

| Вопрос | Решение | Основание |
|---|---|---|
| Шина событий | **Redis Streams** рядом с pub/sub, за флагом `EVENT_STREAM_ENABLED` (выкл.) | Redis уже есть; нужна доставка с подтверждением и догоняющее чтение; в поток идёт компактная отметка, данные — в Ledger. Kafka не нужна: один хост, поток — решения и исполнение, не тики. |
| orjson | **необязательный**, только для шины (`src/infra/fastjson.py`); торговый путь не трогаем | Замер: запись Ledger json 152 мкс против orjson 17 мкс — выигрыш ≈ 0.7 мс на цикл 30 с. |
| uvloop | **не принимается** | Замер: переключение задач asyncio 34 мкс; WS-shadow ≈ 10 сообщений/с на поток → ≈ 340 мкс/с накладных (0.03% CPU). Узкое место — сеть и LLM. Пересмотреть при потоках > 1 000 сообщений/с. |
| Пул процессов для тяжёлой математики | **не нужен** | Замер: шлюз 2.6 мс, признаки 17–20 мс, поиск RAG 8 мс, CVaR 0.17 мс. |
| ONNX-экспорт SAC | **принят, необязателен** (`reinforcement_learning/onnx_export.py`, зависимости `onnx`, `onnxruntime`) | Проверка совпадения с PyTorch (< 1e-4) встроена; бот по-прежнему грузит .zip. |
| Riskfolio-Lib | **не подключается** | Тянет scipy/cvxpy (локально scipy сломан); нужные формулы — в numpy (`src/risk/advanced.py`). Возврат — если докажем OOS-улучшение после издержек. |
| Black–Litterman | реализован как исследование; взгляды — только структурированный JSON с проверкой (не «текст → вес») | BL — модель ожиданий и весов, не замена Kelly/CVaR. |
| Thompson Sampling | реализован, **только после OOS** и с ограничением скорости перелива | ТЗ §Phase 9. |
| Динамический CVaR | фильтрованная историческая симуляция (EWMA-σ) | Статическое окно занижает риск после скачка и завышает после успокоения (тест). |
| Kelly от Meta-Model | только при `usable=True`, с поправкой на неопределённость, потолок 20% | Вероятность без доказанной калибровки в размер не идёт. |
| Smart Execution / Partial Fill / in-flight margin | чистая логика готова, **не подключена** | Сначала замер проскальзывания на Paper (ТЗ §4/5): вход пока рыночный. |
| AI Orchestrator | чистая логика готова, не подключён | Роль выполняет `combine()` по режиму; подключать при появлении Meta-Model и ≥ 2 тяжёлых компонентов. |
